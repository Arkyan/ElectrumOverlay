Créer un widget en 4 étapes

  1. Télécharge l'exemple (bouton en haut) et décompresse-le.
  2. Modifie widget.json (nom, réglages) et widget.html (affichage, comportement).
  3. Pendant que tu travailles, ouvre-le dans ton navigateur pour voir le résultat : installe-le une première fois, puis va sur http://localhost:8080/widgets/<id>/?preview=1 et recharge la page après chaque modification réinstallée.
  4. Compresse le dossier en .zip et importe-le ici. Réimporter un widget avec le même id le met à jour partout.

Ensuite, dans l'éditeur de scène : menu + › Mes widgets. Chaque élément a ses propres réglages, et le widget voyage avec le profil quand tu le partages.

Contenu du .zip

mon-widget/
├── widget.json     description et réglages (obligatoire)
├── widget.html     page du widget (obligatoire, nom modifiable avec "entry")
└── ...             images, sons, polices, scripts : tout ce que tu veux

Limites : 25 Mo et 300 fichiers. Les chemins relatifs (img/logo.png) fonctionnent depuis widget.html.

widget.json

{
  "id": "mon-widget",
  "name": "Mon widget",
  "version": "1.0.0",
  "author": "TonPseudo",
  "description": "Ce que fait le widget",
  "entry": "widget.html",
  "size": { "width": 25, "height": 15 },
  "settings": [
    { "key": "titre", "label": "Titre", "type": "text", "default": "Salut !" },
    { "key": "taille", "label": "Taille (%)", "type": "number", "default": 100, "min": 50, "max": 300, "step": 10 },
    { "key": "couleur", "label": "Couleur", "type": "color", "default": "#22d3ee" },
    { "key": "son", "label": "Jouer un son", "type": "checkbox", "default": true },
    { "key": "mode", "label": "Mode", "type": "select", "default": "simple",
      "options": [{ "value": "simple", "label": "Simple" }, { "value": "detaille", "label": "Détaillé" }] }
  ]
}
ChampRôle
idObligatoire. Minuscules, chiffres et tirets. Identifie le widget : le réimporter avec le même id le met à jour.
nameObligatoire. Nom affiché dans l'éditeur.
version, author, descriptionFacultatifs, affichés dans la liste.
entryPage d'entrée (défaut : widget.html).
sizeTaille de départ du cadre, en % de l'écran (redimensionnable dans l'éditeur).
settingsRéglages proposés dans le panneau de propriétés. type : text, textarea, number (min, max, step), color, checkbox, select (options). default : valeur de départ.

La bibliothèque Electrum

Ajoute-la dans ta page, puis écris ton code dans Electrum.ready :

<script src="/js/electrum-widget.js"></script>
<script>
Electrum.ready(async () => {
  document.body.textContent = Electrum.settings.titre;

  Electrum.on('follow', (e) => console.log('Nouveau follow :', e.user));
  Electrum.on('bits', (e) => console.log(e.user, 'offre', e.amount, 'bits'));

  const stats = await Electrum.getStats();
  console.log(stats.viewerCount, 'viewers');
});
</script>
Propriété / fonctionContenu
Electrum.ready(fn)Lance fn une fois le thème et le contexte chargés.
Electrum.on(type, fn)Appelle fn(données) à chaque événement (liste plus bas). '*' : tous les événements. Renvoie une fonction pour se désabonner.
Electrum.settingsRéglages de cet élément (clés de ton settings).
Electrum.themeCouleurs du thème de la scène : primary, secondary, accent, text, mutedText, panelBg, panelBorder…
Electrum.previewtrue dans l'aperçu de l'éditeur : affiche un exemple pour aider au placement.
Electrum.pageScène qui affiche le widget : starting, index, pause, ending, ou id d'une scène personnalisée.
Electrum.languageLangue de l'interface : fr ou en.
Electrum.channel, Electrum.profileChaîne Twitch (login, id) et profil actif (id, name).
Electrum.getStats()Statistiques du live : isLive, viewerCount, follows, subscribers, chatMessages, title, game, streamDuration.
Electrum.getHistory()Dernières alertes, de la plus récente à la plus ancienne : type, user, detail, time, data (événement Twitch complet).
Electrum.getInteractions()Objectif, sondage, prédiction et hype train en cours (goal, poll, prediction, hypetrain, null si rien).
Electrum.getMusic()Morceau Spotify en cours (title, artist, albumArt, isPlaying) ou null.
Electrum.escapeHtml(texte)Échappe un texte (pseudo, message) avant de l'insérer en HTML.

Les boutons de la page Tests et « Rejouer » du tableau de bord déclenchent ces événements : pratique pour tester.

Couleurs en CSS

La bibliothèque pose aussi les couleurs du thème en variables CSS, mises à jour en direct :

.titre { color: var(--electrum-primary); }
.cadre { background: var(--electrum-panel); border: 2px solid var(--electrum-border); }

Disponibles : --electrum-primary, --electrum-secondary, --electrum-accent, --electrum-text, --electrum-muted-text, --electrum-panel, --electrum-border.

Bon à savoir

  • Garde un fond transparent (background: transparent) pour voir la scène derrière.
  • Le widget est affiché dans son propre cadre : vw et vh se rapportent à ce cadre, pas à l'écran. Avec des tailles en vh, le texte suit la taille du cadre.
  • Changer un réglage dans l'éditeur recharge le widget : il doit savoir repartir de zéro (utilise getStats() ou getHistory() au démarrage).
  • Les sons et vidéos se lancent sans clic dans OBS (dans un navigateur, il faut parfois cliquer d'abord sur la page).
  • Un widget peut appeler l'API locale de l'app : n'importe que des widgets dont tu as confiance dans l'auteur.
