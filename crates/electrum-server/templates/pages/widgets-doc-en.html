Create a widget in 4 steps

  1. Download the example (button at the top) and unzip it.
  2. Edit widget.json (name, settings) and widget.html (look and behavior).
  3. While working on it, open it in your browser to see the result: install it once, then go to http://localhost:8080/widgets/<id>/?preview=1 and reload the page after each reinstalled change.
  4. Zip the folder and import it here. Importing a widget again with the same id updates it everywhere.

Then, in the scene editor: + menu › My widgets. Each element has its own settings, and the widget travels with the profile when you share it.

Content of the .zip

my-widget/
├── widget.json     description and settings (required)
├── widget.html     widget page (required, name can be changed with "entry")
└── ...             images, sounds, fonts, scripts: anything you need

Limits: 25 MB and 300 files. Relative paths (img/logo.png) work from widget.html.

widget.json

{
  "id": "my-widget",
  "name": "My widget",
  "version": "1.0.0",
  "author": "YourName",
  "description": "What the widget does",
  "entry": "widget.html",
  "size": { "width": 25, "height": 15 },
  "settings": [
    { "key": "title", "label": "Title", "type": "text", "default": "Hi!" },
    { "key": "size", "label": "Size (%)", "type": "number", "default": 100, "min": 50, "max": 300, "step": 10 },
    { "key": "color", "label": "Color", "type": "color", "default": "#22d3ee" },
    { "key": "sound", "label": "Play a sound", "type": "checkbox", "default": true },
    { "key": "mode", "label": "Mode", "type": "select", "default": "simple",
      "options": [{ "value": "simple", "label": "Simple" }, { "value": "detailed", "label": "Detailed" }] }
  ]
}
FieldPurpose
idRequired. Lowercase letters, digits and dashes. Identifies the widget: importing it again with the same id updates it.
nameRequired. Name shown in the editor.
version, author, descriptionOptional, shown in the list.
entryEntry page (default: widget.html).
sizeInitial frame size, in % of the screen (resizable in the editor).
settingsSettings shown in the properties panel. type: text, textarea, number (min, max, step), color, checkbox, select (options). default: initial value.

The Electrum library

Add it to your page, then write your code inside Electrum.ready:

<script src="/js/electrum-widget.js"></script>
<script>
Electrum.ready(async () => {
  document.body.textContent = Electrum.settings.title;

  Electrum.on('follow', (e) => console.log('New follow:', e.user));
  Electrum.on('bits', (e) => console.log(e.user, 'cheered', e.amount, 'bits'));

  const stats = await Electrum.getStats();
  console.log(stats.viewerCount, 'viewers');
});
</script>
Property / functionContent
Electrum.ready(fn)Runs fn once the theme and context are loaded.
Electrum.on(type, fn)Calls fn(data) for each event (list below). '*': every event. Returns a function to unsubscribe.
Electrum.settingsSettings of this element (keys from your settings).
Electrum.themeScene theme colors: primary, secondary, accent, text, mutedText, panelBg, panelBorder…
Electrum.previewtrue in the scene editor preview: show a sample to help with placement.
Electrum.pageScene showing the widget: starting, index, pause, ending, or a custom scene id.
Electrum.languageInterface language: fr or en.
Electrum.channel, Electrum.profileTwitch channel (login, id) and active profile (id, name).
Electrum.getStats()Stream stats: isLive, viewerCount, follows, subscribers, chatMessages, title, game, streamDuration.
Electrum.getHistory()Recent alerts, newest first: type, user, detail, time, data (full Twitch event).
Electrum.getInteractions()Current goal, poll, prediction and hype train (goal, poll, prediction, hypetrain, null if none).
Electrum.getMusic()Current Spotify track (title, artist, albumArt, isPlaying) or null.
Electrum.escapeHtml(text)Escapes a text (name, message) before inserting it as HTML.

Events

TypeData
followuser, userId
subuser, tier (1 to 3), months, gifted, message
subgiftuser (null if anonymous), count, tier, anonymous
bitsuser, amount, message, anonymous
raiduser, viewers
chatuser, color, text, html (with emotes), badges, command (starts with !)
streamlive (stream start / end), title, game
channeltitle, game (title or category changed)
goal, poll, prediction, hypetrainphase (begin, progress, lock, end) and their data (same fields as getInteractions())

keykey, down: keyboard/mouse keys, if key display is enabled
themeThe theme changed (profile activated, colors edited): read Electrum.theme again
rawRaw server message, for advanced uses

The buttons on the Tests page and “Replay” on the dashboard trigger these events: handy for testing.

Colors in CSS

The library also sets the theme colors as CSS variables, updated live:

.title { color: var(--electrum-primary); }
.frame { background: var(--electrum-panel); border: 2px solid var(--electrum-border); }

Available: --electrum-primary, --electrum-secondary, --electrum-accent, --electrum-text, --electrum-muted-text, --electrum-panel, --electrum-border.

Good to know

  • Keep a transparent background (background: transparent) to see the scene behind.
  • The widget is shown in its own frame: vw and vh refer to that frame, not the screen. With sizes in vh, text follows the frame size.
  • Changing a setting in the editor reloads the widget: it must be able to start from scratch (use getStats() or getHistory() on startup).
  • Sounds and videos play without a click in OBS (in a browser, you sometimes need to click the page first).
  • A widget can call the app's local API: only import widgets from authors you trust.
