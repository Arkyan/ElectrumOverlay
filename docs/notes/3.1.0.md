## ElectrumOverlay 3.1 — Widgets personnalisés

### 🧩 Crée tes propres éléments de scène
- Nouvelle page **Widgets** : importe un widget (`.zip`), gère ceux que tu as installés, télécharge un exemple pour démarrer.
- Un widget, c'est une page **HTML / CSS / JavaScript** et un fichier `widget.json`. Il reçoit les **événements Twitch** (follow, sub, bits, raid, chat, sondages, prédictions, hype train…), les **statistiques du live**, l'**historique**, la **musique** et les **couleurs du thème**.
- Dans l'**éditeur de scène** : menu **+** › **Mes widgets**. Chaque widget a ses propres réglages dans le panneau de propriétés.
- **Documentation complète** directement dans l'app, en français et en anglais.
- Les widgets sont inclus dans les **sauvegardes** et voyagent avec un **profil partagé** (installés automatiquement à l'import).

### 🛠️ Le reste
- Le plugin **Stream Deck** est maintenant un programme natif : plus besoin de Node.js. Pour le mettre à jour, double-clique sur le fichier `.streamDeckPlugin` de cette release.
- Dépendances surveillées automatiquement pour les correctifs de sécurité.

---

**English:** ElectrumOverlay 3.1 adds **custom widgets**: build your own scene elements in HTML/CSS/JS (Twitch events, stream stats, history, music, theme colors), import them from the new **Widgets** page and place them in the scene editor (+ › My widgets) with their own settings. Full documentation is built into the app. Widgets are included in backups and shared profiles. The Stream Deck plugin is now a native program (no Node.js needed).
