## ElectrumOverlay 3.2.1 — Mise à jour de sécurité

Mise à jour recommandée pour tout le monde : elle corrige plusieurs failles, dont certaines exploitables par un **profil partagé** ou un **widget** piégé, ou par un **site web** ouvert pendant que l'app tourne.

### 🔒 Sécurité
- **Widgets isolés** : un widget lit les données du stream mais ne peut plus modifier tes réglages ni lire tes identifiants.
- **Profils partagés** : un profil ne peut plus injecter de code dans les overlays, détourner l'adresse du serveur, ni faire passer une page web pour une image ou un son.
- **Sites web** : un site ouvert dans ton navigateur ne peut plus modifier ta config, écouter les événements de tes overlays, ni afficher l'app dans un cadre caché.
- **Réseau** : depuis un autre appareil, seuls les overlays sont accessibles (en lecture) ; l'app et ses réglages ne répondent qu'au PC où elle tourne.
- **Twitch et Spotify** : une autorisation qui ne vient pas de l'app est refusée (un lien piégé ne peut plus connecter un autre compte).
- **Imports** : taille des zips vérifiée une fois décompressés ; bibliothèque zip mise à jour.
- **Liens externes** : seules les pages web s'ouvrent depuis l'app.

### 🔧 Corrections
- Subs offerts comptés une seule fois dans les statistiques.
- App ouverte en plein live : le live est repris (durée, titre, jeu).
- Écran de fin : la durée du live reste affichée après la fin du stream.
- Bandeau du bas supprimé dans l'éditeur : il ne réapparaît plus.
- Messages de pause modifiés : appliqués sans recharger OBS.
- Interface en anglais : tes textes (messages, réponses de commandes, thèmes) ne sont plus traduits par erreur.
- Échec d'installation d'une mise à jour : l'app repart normalement.
- Plugin Stream Deck : liste des profils corrigée, connexion à `localhost` fiabilisée.

### ⚠️ À savoir
- **Stream à deux PC** : le plugin Stream Deck doit être sur le PC où tourne ElectrumOverlay.
- **Widgets personnalisés** : un widget ne peut plus utiliser `localStorage`, ouvrir de fenêtre ni modifier les réglages.

---

**English:** security update, recommended for everyone. Widgets now run sandboxed (they read stream data but cannot change settings or read credentials); shared profiles can no longer inject code into overlays, redirect them or disguise a web page as media; websites open in your browser can no longer change your config, listen to overlay events or frame the app; other devices on the network can only read the overlays; Twitch/Spotify authorizations not started by the app are refused; zip imports are size-capped. Also fixes gifted subs being counted twice, live state when the app opens mid-stream, stream duration on the ending screen, deleted bottom bar reappearing, pause messages not updating live, user texts being translated in English, recovery after a failed update install, and the Stream Deck profile list. Note: the Stream Deck plugin must run on the PC running ElectrumOverlay, and custom widgets can no longer use `localStorage`, open windows or change settings.
